# UI Notes — Masarah HR

## 1. Branding & Header

- The logo, company name, and license number must be clearly visible
- License number: 304
- The license number should be prominent and easy for the customer to read
- Page colors should be visually consistent with the logo
- Replace the Ministry of Human Resources and Social Development logo with the modern version
- Add the official license number prominently, including a dedicated section at the bottom of the page

## 2. Typography

- Use Font 8 Bold for headings
- Use Font 8 Medium for body text
- The large decorative headings look premium but are difficult to read quickly, especially in long sentences
- Prioritize readability over decorative styling
- Avoid using two typography styles that feel completely unrelated
- Prefer one font family with multiple weights:
  - Bold for headings
  - Regular/Medium for body text
- The contrast between the decorative heading font and simple body font should be reduced

## 3. Colors & Contrast

- Maintain a consistent color system throughout the website
- Backgrounds currently switch between navy and cream without a clear visual pattern
- Establish a consistent section pattern instead of changing backgrounds randomly
- Example:
  - Information/content sections → Cream
  - CTA sections → Navy
- Light-gray text on dark navy backgrounds has insufficient contrast in some areas
- Light-gold text on cream backgrounds is also difficult to read
- Gold is currently overused across:
  - Buttons
  - Separators
  - Icons
  - Stars
  - Other UI elements
- Reserve gold primarily for important action elements such as CTA buttons
- Use calmer colors such as gray and light navy for secondary elements

## 4. Layout & Spacing

- The cards for packages, countries, and testimonials are well organized and evenly sized
- The overall whitespace is good
- The page is not overcrowded and is generally comfortable to read
- Maintain consistent spacing and alignment across all sections
- The entire website should feel like one unified design system rather than separate templates combined together

## 5. Packages UI

- Remove the General Recruitment section completely
- Remove the Professional Staff section completely
- Update the package cards with the proposed domestic-worker and private-driver packages
- Keep package cards visually consistent in size, spacing, hierarchy, and CTA treatment

## 6. Companies Section

- Remove the Companies section completely
- Remove anything related to companies from the UI
- Add the letter "ة" to the "For Families" section where indicated

## 7. Icons

- Replace the existing icons with different shapes if possible
- Keep the new icons visually consistent with the overall design system
- Avoid excessive use of gold for every icon

## 8. Government Logos & Carousel

- Government logos are duplicated in the carousel
- The Musaned / Foreign Affairs logos appear twice next to each other
- Check the carousel implementation
- Make sure there is no infinite-loop issue leaving the carousel empty
- Ensure all carousel content is populated correctly
- Fix the repeated logos as an implementation/UI issue

## 9. Testimonials / Reviews

- The "4.9/5 Google Verified" claim needs a visible verification source
- If the rating is actually verified, connect it to an external Reviews source
- The customer should be able to independently verify the rating
- Avoid displaying a verification claim without a verifiable source

## 10. Homepage Hero / Main Content

- Add a stronger primary message at the top of the homepage
- Example:
  "Your main destination
  for a unique recruitment experience that meets your expectations"
- Make the primary heading immediately readable and visually prominent
- Keep the hero typography clear rather than overly decorative

## 11. Recruitment Process Section

- Update the recruitment-process content
- Use the referenced recruitment-process design as an example
- Keep the process visually clear and easy to scan
- The icons/process steps should have consistent spacing and visual hierarchy

## 12. Guarantee Section

- Display the 60-day guarantee clearly
- Suggested wording:
  "60-day guarantee — We guarantee the worker for up to two months"

## 13. Footer

- Replace "Follow Masarah" with "Find Us On"
- Remove the word "Platform" from the website
- Add the company's geographical location using a Google Maps component
- Ensure the footer contains the required social accounts:
  - X: masarah_hr
  - Instagram: masarah_hr
  - Facebook: masarah_hr
  - WhatsApp: masarah_hr

## 14. Overall UI Consistency

- Establish one coherent visual language across the entire website
- Avoid mixing unrelated templates or design styles
- Keep:
  - Typography consistent
  - Background patterns consistent
  - Spacing consistent
  - Icon styles consistent
  - Button styles consistent
  - Card styles consistent
  - Color hierarchy consistent
- Use gold selectively rather than as the default color for every highlighted element
- Prioritize readability, especially for headings and supporting text
- Preserve the existing good whitespace and card organization while correcting the inconsistencies
